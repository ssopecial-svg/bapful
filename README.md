# 밥풀 프로토타입

피그마 화면 이미지를 픽셀 그대로 잘라서 쓰고, 그 위에 터치 영역·애니메이션만 얹은 모바일 웹 프로토타입입니다.
빌드 과정이 없는 순수 HTML이라 Vercel에 그대로 올리면 됩니다.

## 폴더 구조
```
index.html             ← 시작 파일 (반드시 저장소 맨 위에 있어야 함)
style.css              ← 스타일
app.js                 ← 화면 흐름 / 인터랙션 (좌표는 원본 이미지 603px 기준)
manifest.webmanifest   ← 홈 화면에 추가했을 때 앱처럼 보이게 하는 설정
icon-192.png, icon-512.png, apple-touch-icon.png  ← 앱 아이콘
assets/                ← 디자인에서 잘라낸 이미지들
```

## 화면 흐름
스플래시(2.3초 후 자동) → 온보딩 4장(스와이프/다음) → 로그인 → 약관 → 기본 정보 → 요리 취향 → 우선순위 → 알림 설정 → 냉장고 채우기 → 홈

- 로그인 화면 `둘러보기` → 바로 홈
- `<` 뒤로가기, `건너뛰기` 동작 / 안드로이드 뒤로가기 버튼도 동작
- 홈의 `밥풀` 로고를 1초 길게 누르면 처음(스플래시)부터 다시 시작
- 특정 화면 바로 열기: 주소 뒤에 `#home`, `#terms`, `#info` 처럼 붙이기

## 수정하고 싶을 때
- 화면 이미지를 바꾸려면 `assets/` 안의 같은 이름 파일을 교체 (크기·위치가 같아야 함)
- 화면 순서를 바꾸려면 `app.js`에서 `go('화면이름')` 부분 수정
- GitHub에서 파일을 고치고 저장(Commit)하면 Vercel이 1분 안에 자동으로 다시 배포합니다
